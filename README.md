### [Course Timetable Recommendation System](https://github.com/adeanggi7/course-timetable-recommender)

A generative-AI-assisted team project completed for a Computational Mathematics course.

- Proposed a timetable recommendation problem based on constraints commonly considered by university students
- Compared Q-learning, genetic algorithms, and K-means before selecting the final approach
- Defined timetable constraints, numerical features, and the overall recommendation workflow
- Used generative AI to generate most of the implementation code, then tested the prototype and directed revisions
- Identified issues involving timetable rendering, course requirements, cluster labels, and candidate-generation order
- Analyzed how data quality, heuristic rules, and manually designed scores affected the recommendations
- Documented the development process, limitations, and lessons learned

**Methods:** K-means clustering · PCA visualization · Min-max normalization · Rule-based scoring  
**Technologies:** HTML · CSS · JavaScript · JSON
