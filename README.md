## Projects

### [Course Timetable Recommendation System](https://github.com/adeanggi7/course-timetable-recommender)

A generative-AI-assisted team project completed for a Computational Mathematics course.

- Proposed a timetable recommendation problem based on constraints commonly considered by university students
- Compared Q-learning, genetic algorithms, and K-means before selecting the final approach
- Defined timetable constraints, numerical features, and the overall recommendation workflow
- Tested the generated prototype, identified problems, and directed revisions
- Analyzed how data quality, heuristic rules, and manually designed scores affected the recommendations
- Documented the development process, limitations, and lessons learned

**Methods:** K-means clustering · PCA visualization · Min-max normalization · Rule-based scoring  
**Technologies:** HTML · CSS · JavaScript · JSON

### [Cafe Kiosk Frontend](https://github.com/adeanggi7/cafe-kiosk-frontend)

A frontend project completed for Industrial Mathematics I using a course-provided REST API.

- Built customer-facing kiosk and administrator menu management interfaces
- Implemented category filtering and dynamic menu rendering
- Managed cart state, quantity controls, item removal, and total calculation
- Implemented simulated payment selection and receipt display
- Connected the frontend to the provided REST API using the Fetch API
- Implemented menu creation, editing, deletion, and client-side validation

The public repository contains only the frontend code. The server, database, and REST API infrastructure were provided as course materials.

**Technologies:** HTML · CSS · JavaScript · DOM API · Fetch API
